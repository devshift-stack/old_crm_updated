📦 SCHNELLSTART:
═══════════════════════════════════════════════════════════

1. Entpacken:
   unzip mac_assistant_v4.0_COMPLETE.zip
   cd mac_assistant

2. Setup:
   ./setup.sh

3. .env erstellen:
   cp .env.example .env
   nano .env  # API Keys einfügen

4. Starten:
   python3 main.py
