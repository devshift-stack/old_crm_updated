📋 SCHNELLSTART (5 MINUTEN!):

  1️⃣  INSTALLATION

      cd mac_assistant
      python3 -m venv venv
      source venv/bin/activate
      pip install -r requirements.txt

  2️⃣  KONFIGURATION

      cp .env.example .env
      nano .env

      → Setze deine API Keys:
        ANTHROPIC_API_KEY=sk-ant-dein-key

      → Aktiviere Cloud Agents:
        ENABLE_SLACK_BOT=true
        SLACK_BOT_TOKEN=xoxb-dein-token
        SLACK_APP_TOKEN=xapp-dein-token

        ENABLE_WEB_SERVER=true
        WEB_SERVER_PORT=5000

  3️⃣  STARTEN

      python3 main.py

      → Dashboard öffnet automatisch!
      → Cloud Agents starten automatisch!

  4️⃣  REMOTE ACCESS NUTZEN

      🔹 Slack: Schreibe @Mac Assistant in deinem Workspace
      🔹 Web: Öffne http://localhost:5000
      🔹 Mobile: Nutze Slack App von unterwegs!

🎯 CLOUD AGENT SETUP:

  ═══ SLACK BOT (Empfohlen!) ═══

  1. https://api.slack.com/apps → "Create New App"
  2. Socket Mode aktivieren → App Token kopieren
  3. Bot Token Scopes hinzufügen (siehe CLOUD_AGENTS.md)
  4. Bot installieren → Bot Token kopieren
  5. In .env eintragen:

     ENABLE_SLACK_BOT=true
     SLACK_BOT_TOKEN=xoxb-...
     SLACK_APP_TOKEN=xapp-...

  6. App starten → Bot ist live! 🎉

  Befehle:
  - /status → System-Status
  - /email → E-Mails prüfen
  - /messages → Alle Nachrichten
  - /photos recent → Fotos
  - /tasks Befehl → Task ausführen
  - @Mac Assistant fragen... → Natural Language

  ═══ WEB SERVER ═══

  1. In .env aktivieren:
     ENABLE_WEB_SERVER=true
     WEB_SERVER_PORT=5000

  2. App starten

  3. Browser öffnen: http://localhost:5000

  Im Netzwerk erreichbar unter: http://deine-mac-ip:5000

  ═══ CLOUD SYNC ═══

  1. In .env konfigurieren:
     ENABLE_CLOUD_SYNC=true
     CLOUD_SYNC_DIR=~/Dropbox/MacAssistant
     CLOUD_SYNC_INTERVAL=3600  # 1 Stunde

  2. App starten → Automatisches Backup läuft!
